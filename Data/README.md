# Dataset notes

This directory contains the legal documents used to build the retrieval index.
The application code is covered by the repository's MIT license; that license does
not automatically grant rights to third-party documents in this directory.

Before redistributing these files, record the official source URL, publication
date, and reuse terms for every PDF and CSV. If reuse permission is uncertain,
remove the affected file from the public repository and provide download
instructions instead.

The official [Laws of Bangladesh](https://bdlaws.minlaw.gov.bd/) portal is the
preferred reference for checking current Act text. The exact origin of the two CSV
files cannot be established from their filenames alone and still needs to be
documented by the repository owner.

The two large CSV files make the repository substantially larger. A future release
should keep a small, documented sample in Git and publish the full corpus through a
versioned dataset host.
